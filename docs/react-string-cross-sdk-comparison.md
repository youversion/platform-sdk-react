# React strings compared with sibling SDKs

Verified on 2026-11-04. This report compares the 33 React-specific keys used after the shared-key migration in React commit `ea09a5220a8bf92a971e576be6abe7cab1f900cb`.

## Revisions

- `kotlin` at fetched `origin/main` commit `ed02fd04de080af4752af58c613abe97068a4ca4`.
- `swift` at fetched `origin/main` commit `84b6b7b34965b2279eb474d6e73cea9ddce2a4e6`.
- `reactnative-expo` at fetched `origin/main` commit `c971b078dfe6c4df9c94903686c25020dc0f6f1b`.

## Findings

- Eight React values have exact matches at Expo native production call sites.
- A ninth key, `versionsStatistics`, has a used Kotlin equivalent and a used Swift pluralized equivalent. `signInParagraph` also has equivalent copy in Kotlin and Swift.
- Eleven more keys have related wording or related UI roles. Their differences are recorded below; they are not approved substitutions.
- `userAvatarAlt` is an exact Expo English catalog entry without a native production reference found.
- Twelve keys have no clear dedicated counterpart in the other SDK-owned UI catalogs and production source examined.

A duplicate in multiple SDKs is a candidate for shared ownership, not proof that a shared root key already exists. The eight exact Expo matches remain platform-prefixed upstream.

## Scope and verification limits

- Parsed Android default-language XML, resolved SDK R.string aliases, read the Swift English xcstrings catalog including plural variants, and read Expo English JSON.
- Verified matches in production sources at the pinned revisions. Tests, examples, and previews were not evidence of active SDK copy.
- Fuzzy matching generated candidates only. The reported close matches were checked for wording and role differences. Similar error words alone did not establish equivalence.
- Expo DOM wrappers reuse the React web SDK. Inherited React copy is not counted as a second native implementation.
- No app builds, devices, or rendered UI runs were needed or performed for this source-and-catalog inspection.
- No shared-key migration or upstream changes are proposed or applied by this report.
